# Night Bloom 🌸

A flower scene created with Python Turtle Graphics featuring layered petals, custom hex color gradients, leaves, and a starry night background.

![Flower](flower.png)

## Features

- Draws a flower using Python Turtle Graphics
- Uses layered petals for depth and symmetry
- Custom hex color palette
- Procedurally generated stars
- Randomized petal variations for a natural look

## Technologies

- Python 3
- Turtle Graphics
- Math
- Random

## How to Run

1. Clone the repository
2. Run:

```bash
python flower.py
```

## How To personalize

There's a few ways you could personalize your flower's petals, one of those is by using the color's name:

```bash
(8, 120, "red", "light pink"),
```
The other way, is by using Hex codes. This one i highly recommend as it gives you more freedom in choosing.
```bash
(8, 120, "#8b1e5a", "#b12f73"),
```
